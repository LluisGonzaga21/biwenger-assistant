What's actually under the hood

Fair-value estimation

Compares every market listing against similar players in the same league to flag bargains and overpriced tags — not a generic price.

Resumable data pipeline

The API caps requests mid-download. Every player's detail is cached the moment it's fetched, so an interrupted run picks up exactly where it left off.

Dry-run-safe by default

Bids and clause buyouts print the exact payload first. Nothing touches your real balance until you explicitly confirm it.

Bid-to-win, not bid-to-list

Recommended offers factor in real comparable sale prices and rival budgets — never just the asking price.
